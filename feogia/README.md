# A Volta ao Mundo com Feogia

Jogo educativo de Geografia para 6º e 7º ano.

## Versão atual
- seleção por série (6º e 7º ano)
- três níveis por série: Explorador, Cartógrafo e Mestre
- banco ampliado para 120 questões (20 por combinação série/nível)
- 10 questões sorteadas por partida
- habilidades BNCC exibidas em cada questão
- dicas, feedback pedagógico, pontuação, classificação e revisão final
- voz da Feogia via Web Speech API quando suportada pelo navegador
- efeitos sonoros e animações
- cenários fornecidos pelo usuário: Amazônia, Pantanal, Serra Gaúcha, Chapada Diamantina, Lençóis/Delta do Piauí, Ceará, Litoral/Agreste e Caatinga/Recôncavo
- layout responsivo para celular e computador

## Execução
Imagem estática servida por Nginx via Docker.
